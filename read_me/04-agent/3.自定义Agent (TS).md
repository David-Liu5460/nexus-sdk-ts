自定义 Agent
当内置的 `BaseAgent` 无法满足需求时，可以通过实现 `Agent` 接口来创建完全自定义的 Agent。

> 本文是 [`3.自定义Agent.md`](./original/3.自定义Agent.md)（Go 版）的 TypeScript 对应版本，基于 Bun + TS SDK 实际代码（`src/agent/agent.ts`）编写。文末附 **Go ↔ TS API 映射表**，并标注两版的差异点。

---
Agent 接口（`src/agent/agent.ts`）

```ts
import type { Context } from "nexus-sdk-ts";
import type { ChatCompletionMessage, ChatCompletionResponse } from "nexus-sdk-ts";
import type { GenerateOptions } from "nexus-sdk-ts";

export interface Agent {
  run(
    ctx: Context,
    messages: ChatCompletionMessage[],
    opts?: GenerateOptions,
  ): Promise<ChatCompletionResponse>;
  // 续跑：在 askUser 中断后，喂入用户回答并从中断点继续 ReAct 闭环
  resume(
    ctx: Context,
    answer: string,
    opts?: GenerateOptions,
  ): Promise<ChatCompletionResponse>;
  name(): string;
  description(): string;
  stop(): void;
}
```

> 差异：Go 接口只有 `Run/Name/Description/Stop`；TS 接口**多了一个 `resume`**，用于 Human-in-Loop 续跑。自定义 Agent 必须实现它（不需要续跑能力时可抛错或退化为再次 `run`）。

---
最简实现示例

```ts
import type { Agent } from "nexus-sdk-ts";
import type { Context } from "nexus-sdk-ts";
import type { ChatCompletionMessage, ChatCompletionResponse } from "nexus-sdk-ts";
import { ErrStop } from "nexus-sdk-ts";

// EchoAgent：将用户最后一条消息原样返回
export class EchoAgent implements Agent {
  private stopped = false;
  constructor(private readonly agentName: string) {}

  name() { return this.agentName; }
  description() { return "将用户输入原样返回的 Echo Agent"; }
  stop() { this.stopped = true; }

  async run(
    ctx: Context,
    messages: ChatCompletionMessage[],
    _opts?,
  ): Promise<ChatCompletionResponse> {
    if (this.stopped) throw new ErrStop();

    // 获取用户最后一条消息：优先入参，否则回看 Context
    let lastContent = "";
    if (messages.length > 0) {
      lastContent = messages[messages.length - 1]!.content ?? "";
    } else {
      const history = ctx.loadAllMessages();
      if (history.length > 0) lastContent = history[history.length - 1]!.content ?? "";
    }

    const message: ChatCompletionMessage = {
      role: "assistant",
      content: "Echo: " + lastContent,
      name: this.agentName,
    };
    ctx.addMessage(message);
    return { message, finishReason: "stop" };
  }

  async resume(ctx: Context, answer: string): Promise<ChatCompletionResponse> {
    // 简单 Agent：把回答当作新一轮 user 输入再跑一遍
    return this.run(ctx, [{ role: "user", content: answer }]);
  }
}
```

> 差异：Go 用 `var _ schema.Agent = (*EchoAgent)(nil)` 做编译期接口检查；TS 用 `implements Agent` 由编译器保证完整实现。Go 的 `schema.ChatCompletionResponse{ Choices: [...] }` 是数组结构，TS 的 `ChatCompletionResponse` 直接是 `{ message, finishReason }`（**没有 Choices 包一层**）。

带 LLM 的自定义 Agent
以下是一个包含自定义逻辑的 Agent 示例：

```ts
import type { Agent, Context } from "nexus-sdk-ts";
import type { ChatCompletionMessage, ChatCompletionResponse, LLM, GenerateOptions } from "nexus-sdk-ts";
import { ErrStop, newSystemMessage } from "nexus-sdk-ts";

export class ChainOfThoughtAgent implements Agent {
  private stopped = false;
  constructor(private readonly agentName: string, private readonly llm: LLM) {}

  name() { return this.agentName; }
  description() { return "使用思维链的推理 Agent"; }
  stop() { this.stopped = true; this.llm.stop(); }

  async run(
    ctx: Context,
    messages: ChatCompletionMessage[],
    opts?: GenerateOptions,
  ): Promise<ChatCompletionResponse> {
    if (this.stopped) throw new ErrStop();

    // Step 1: 构造思维链提示
    const cotPrompt: ChatCompletionMessage[] = [
      newSystemMessage("请先逐步思考，再给出最终答案。格式：\n思考：...\n答案：..."),
    ];
    cotPrompt.push(...(messages.length > 0 ? messages : ctx.loadAllMessages()));

    // Step 2: 调用 LLM
    const resp = await this.llm.generateContent(cotPrompt, opts);

    // Step 3: 保存结果到 Context
    ctx.addMessage(resp.message);
    return resp;
  }

  async resume(ctx: Context, answer: string, opts?: GenerateOptions) {
    return this.run(ctx, [{ role: "user", content: answer }], opts);
  }
}
```

> 差异：Go 的 `llm.GenerateContent(ctx, nctx, prompt, opts...)` 带双 Context + 变长 opts；TS 的 `llm.generateContent(messages, opts?)`（`src/llm/llm.ts`）只接收消息数组和单个 `GenerateOptions`。消息构造器从 `llm.NewSystemMessage(name, content)` 变为 `newSystemMessage(content)`（**无 name 参数**，见 `src/llm/message.ts`）。

在 Graph 中使用自定义 Agent

```ts
import { gotoEnd } from "nexus-sdk-ts";

g.addNode({
  name: "custom_node",
  func: async (ctx, registerStop) => {
    const myAgent = new ChainOfThoughtAgent("cot_agent", llmClient);
    // 注册停止函数：Graph 关闭时自动停止
    registerStop(() => myAgent.stop());

    const resp = await myAgent.run(ctx, []);
    ctx.set("cot_result", resp.message.content ?? "");
    return gotoEnd();   // 或 return null 交给边路由
  },
});
```

> 差异：Go 节点签名是 `func(ctx, nctx, reg, cb)`；TS 的 NodeFunc 是 `(ctx, registerStop, callback?) => Promise<Command | null>`（`src/core/node.ts`）。返回 `null` 表示交给边路由，返回 `Command`（如 `gotoNode` / `gotoEnd`）表示显式路由。

最佳实践
1. 编译期接口检查

```ts
// implements 即可让 TS 在编译期校验接口完整性
export class MyAgent implements Agent { /* ... */ }
```

2. 正确处理 Stop 信号

```ts
async run(ctx: Context, messages: ChatCompletionMessage[]) {
  for (let i = 0; i < maxIter; i++) {
    if (this.stopped) throw new ErrStop();   // 循环开始时检查
    // ...
  }
}
```

3. 遵循消息读写约定

```ts
// 写入：把产出落回 Context，供后续节点 / 轮次读取
ctx.addMessage(resp.message);
// 读取：加载全部历史（可配合 filterEmptyMessage 过滤空占位）
const history = ctx.loadAllMessages();
```

4. 支持中断与续跑

```ts
async resume(ctx: Context, answer: string, opts?: GenerateOptions) {
  // 把用户回答追加为 user 消息后从中断点续跑
  ctx.addMessage({ role: "user", content: answer });
  ctx.getInterruptionState().interruptionType = InterruptionType.None;
  return this.run(ctx, [], opts);
}
```

5. 支持 Callback

```ts
async run(ctx: Context, messages: ChatCompletionMessage[]) {
  await this.callback?.onAgentStart?.(this.name(), messages);
  try {
    const resp = /* ... */;
    await this.callback?.onAgentEnd?.(this.name(), resp);
    return resp;
  } catch (e) {
    await this.callback?.onAgentEnd?.(this.name(), undefined, e as Error);
    throw e;
  }
}
```

> 差异：Go 的 Callback 是 `AgentStartCallback(ctx, nctx, agent, messages, ...)`；TS 的 `Callback`（`src/callback/callback.ts`）所有方法可选，签名为 `onAgentStart(agentName, messages)` / `onAgentEnd(agentName, result, err?)`，并支持事件流回调（`onAnswer` / `onToolCall` / `onToolResult` 等）。

可运行示例
完整可离线运行的示例见 [`examples/custom-agent.ts`](../../examples/custom-agent.ts)，演示了上文两个自定义 Agent（`EchoAgent` 无 LLM、`ChainOfThoughtAgent` 用 MockLLM），均实现完整的 `Agent` 接口（`run` / `resume` / `name` / `description` / `stop`）。

```bash
bun run examples/custom-agent.ts
# 或
bun run custom:agent
```

预期输出：

```
=== Demo 1: EchoAgent（无 LLM）===

[resume] Echo: 再回显一句

=== Demo 2: ChainOfThoughtAgent（MockLLM 离线）===

思考：用户在问候。

[消息轨迹] assistant
```
