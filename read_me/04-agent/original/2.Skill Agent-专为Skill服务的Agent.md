SkillAgent 是专门用于加载和执行"技能文件"（Skill）的 Agent。技能文件是一种结构化的任务定义，包含提示词模板、执行逻辑和依赖声明，适合将复杂能力封装成可复用的技能单元。

> 📘 TypeScript 版本见 [`2.Skill Agent-专为Skill服务的Agent (TS).md`](../2.Skill%20Agent-专为Skill服务的Agent%20(TS).md)。注意：TS SDK 当前**尚未移植 SkillAgent**，该文说明现状并给出基于 BaseAgent 的等价替代思路。

---
概述
SkillAgent 继承自 BaseAgent，扩展了以下能力：
- 本地技能：从本地目录加载技能文件
- 远程技能：通过技能 ID 从 OceanAI 平台拉取技能
- 沙箱执行：技能代码在隔离的沙箱环境中执行
- 渐进式工具加载：Skill 元数据中声明依赖的 MCP Server，LLM 按需加载，避免一次性注册占用上下文（默认开启）
SkillAgent 根据传入技能数量自动切换工作模式：

单技能模式
多技能模式

工具准备
使用skillAgent必须提供文件读取的工具（NewReadFileTool），常用的工具如下，可直接复制使用（也可根据需求自行选择其它工具是否使用），其中sandbox参数可指定本地文件系统，也可指定远程fass的sandbox，若有其它实现需求也可自行实现对应接口，详见3. 沙箱执行

```go
func fileTools(sb sandbox.SandBox) []schema.BaseTool {
    ts := make([]schema.BaseTool, 0, 10)
    ts = append(ts, file.NewCreateDirTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewListFileTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewPwdTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewReadFileTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewWriteFileTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewCommandTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewUnZIPTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewReadPDFFileTool(file.WithSandbox(sb)))
    ts = append(ts, file.NewConcatFileTool(file.WithSandbox(sb)))
    return ts
}
```

单技能模式
传入 1 个 SkillDef 时进入单技能模式。此时 Metadata（通常为 SKILL.md 的文本内容）会预加载进系统提示，LLM 启动时即获得完整的执行蓝图，直接按 Metadata 中定义的工作流执行。
Metadata 字段在此模式下必须提供，且 Name、Desc、Path 也均为必填。

```go
skillAgent, err := agent.NewSkillAgent(
    agent.WithName("data_analyst"),
    agent.WithDesc("数据分析专用 Agent"),
    agent.WithLLM(llmClient),
    agent.WithSkillRootPath("skills/"),
    agent.WithSkills(
        agent.SkillDef{
            Name:     "data_analysis",
            Path:     "skills/data_analysis",
            Desc:     "数据分析技能",
            Metadata: metadataContent, // 必须：SKILL.md 的文本内容
        },
    ),
)
```

---
多技能模式
传入 2 个及以上 SkillDef 时进入多技能模式。LLM 拿到的是所有技能的名称、描述和路径列表，需要根据用户请求动态选择合适的技能，再通过文件工具读取对应目录下的 SKILL.md 来获取执行详情。
此模式下 Metadata 字段不需要传入，Name、Desc、Path 为必填。

```go
skillAgent, err := agent.NewSkillAgent(
    agent.WithName("universal_skill_agent"),
    agent.WithDesc("通用技能调度 Agent"),
    agent.WithLLM(llmClient),
    agent.WithSkillRootPath("skills/"),
    agent.WithSkills(
        agent.SkillDef{
            Name: "web_research",
            Path: "skills/web_research",
            Desc: "网页搜索与信息整合",
            // Metadata 不需要，LLM 会按需读取 skills/web_research/SKILL.md
        },
        agent.SkillDef{
            Name: "data_analysis",
            Path: "skills/data_analysis",
            Desc: "数据分析与可视化",
        },
        agent.SkillDef{
            Name: "code_review",
            Path: "skills/code_review",
            Desc: "代码审查与优化建议",
        },
    ),
)
```

多技能模式下，LLM 会经历以下流程：
用户请求 → 分析需求 → 匹配技能列表
         → 选定技能（告知用户）
         → 读取对应 SKILL.md
         → 按 SKILL.md 中的工作流执行
         → 如有需要，按需加载 MCP 工具

---
SkillDef 结构

```go
type SkillDef struct {
    Name     string  // 技能名称
    Path     string  // 技能目录路径（相对于 root 或绝对路径）
    Desc     string  // 技能描述（LLM 根据此选择技能）
    Metadata string  // 技能元数据内容（单技能模式必须；多技能模式不需要）
}
```

远程技能（通过技能 ID）
从 OceanAI 平台下载技能到沙箱：

```go
import "code.byted.org/ad/nexus/pkg/sandbox"
sb := sandbox.NewLocalSandBox("/tmp/skill_sandbox")
skillAgent, err := agent.NewSkillAgent(
    agent.WithName("remote_skill_worker"),
    agent.WithDesc("远程技能执行 Agent"),
    agent.WithLLM(llmClient),
    agent.WithSkillRootPath("skills/"),
    agent.WithSkillIds("skill-id-001", "skill-id-002"), // 远程技能 ID
    agent.WithSkillSandbox(sb),                          // 使用远程技能时必须
)
```

渐进式工具加载（仅支持 OceanAI MCP Server 管理平台 上的工具）
SkillAgent 默认开启渐进式工具加载（WithProgressiveToolLoading(true)）。开启后会自动注入内置工具 skill_mcp_loader。
LLM 执行 Skill 时，根据 Skill 的 SKILL.md 中声明的 MCP Server 依赖，在需要某个工具时才调用 skill_mcp_loader 按需加载，而非启动时注册所有工具，可显著减少上下文 Token 占用。
在 SKILL.md 中声明依赖
在 Skill 的 SKILL.md（或单技能模式的 Metadata）中添加 Dependencies 章节：
## Dependencies
本技能依赖以下外部工具，执行前请通过 skill_mcp_loader 按需加载：
| MCP Server ID          | 用途         | 所需工具                       |
|------------------------|------------|-------------------------------|
| `mcp-web-search-001`   | 网页搜索     | `web_search`                  |
| `mcp-database-002`     | 数据库查询   | `sql_query`, `list_tables`    |
MCP Server ID 在 OceanAI MCP Server 管理平台 上查看和管理。
skill_mcp_loader 工具参数
参数
类型
说明
mcp_server_id
string（必须）
OceanAI 平台上的 MCP Server ID
tool_names
[]string（可选）
要加载的工具名列表；为空时返回该 Server 的所有可用工具列表
关闭渐进式加载工具

```go
agent.WithProgressiveToolLoading(false)
```

---
在 Graph 中使用

```go
g.AddNode("skill_node", func(ctx context.Context, nctx schema.Context,
    reg func(func(schema.Context)), cb schema.Callback) (*schema.Command, error) {
    skillAgent, err := agent.NewSkillAgent(
        agent.WithName("skill_executor"),
        agent.WithDesc("执行专业技能"),
        agent.WithLLM(llmClient),
        agent.WithSkillRootPath("skills/"),
        agent.WithSkills(agent.SkillDef{
            Name:     "data_analysis",
            Path:     "skills/data_analysis",
            Desc:     "数据分析技能",
            Metadata: metadataContent,
        }),
        agent.WithCallback(cb),
    )
    if err != nil {
        return nil, err
    }
    resp, err := skillAgent.Run(ctx, nctx, nil)
    if err != nil {
        return nil, err
    }
    nctx.Set("result", resp.Choices[0].Message.Content)
    return schema.GotoNode("next"), nil
})
```

---
注意事项
1. 单技能模式 Metadata 必填：WithSkills 传入 1 个技能时，Metadata 字段必须非空（SKILL.md 的完整文本内容），缺失会返回错误。
2. 多技能模式无需 Metadata：WithSkills 传入 2 个及以上技能时，只需 Name、Desc、Path，LLM 会在运行时按需读取各技能目录下的 SKILL.md。
3. 根目录配置：WithSkillRootPath 是必须的，技能文件路径相对于此根目录解析。
4. 远程技能需要沙箱：使用 WithSkillIds 时必须同时设置 WithSkillSandbox，否则创建时会返回 ErrMissingSandbox。
5. MCP Server ID 来源：skill_mcp_loader 的 mcp_server_id 必须来自 SKILL.md 的显式声明或用户消息，LLM 不能猜测或推断 Server ID。
6. 继承 BaseAgent 行为：SkillAgent 的 Run() 方法与 BaseAgent 完全相同。
