等价替代：用 BaseAgent + 工具自行拼装

SkillAgent 的核心是"把技能说明（SKILL.md）作为系统提示 + 用文件工具按需读取技能内容"。在 TS 侧可以用 `BaseAgent` 直接拼装出**单技能模式**的等价效果：

```ts
import { BaseAgent, MemoryContext, newUserMessage } from "nexus-sdk-ts";

// 把 SKILL.md 的文本内容直接作为 instruction（相当于单技能模式的 Metadata 预加载）
const skillMetadata = await Bun.file("skills/data_analysis/SKILL.md").text();

const skillAgent = new BaseAgent({
  name: "data_analyst",
  description: "数据分析专用 Agent",
  llm: llmClient,
  instruction: `你是一个按以下技能说明工作的执行体，请严格遵循其中的工作流：\n\n${skillMetadata}`,
  // tools: [...],   // 技能执行所需的工具（需自行实现 BaseTool）
});

const ctx = new MemoryContext({ query: "分析这份销售数据" });
const resp = await skillAgent.run(ctx, [newUserMessage(ctx.userQuery())]);
console.log(resp.message.content);
```

多技能模式（让 LLM 先选技能、再读对应 SKILL.md）需要先实现文件读取工具（实现 `BaseTool`，在 `call()` 里读取技能目录下的文件），再把"技能名 + 描述 + 路径"列表写进 `instruction`，由 LLM 决定读哪一个。这部分 TS 侧没有现成工具，需自行补齐。

---
若要在 TS 中正式支持 SkillAgent，需要补齐
1. **文件工具集**：实现 `BaseTool` 的 ReadFile / ListFile / WriteFile / Command 等（对应 Go 的 `file.NewReadFileTool` 等）。
2. **Sandbox 抽象**：本地 / 远程沙箱接口（对应 Go 的 `sandbox.SandBox`）。
3. **SkillAgent 类**：继承 / 组合 `BaseAgent`，支持 `SkillDef` 列表、单 / 多技能模式切换、`SkillRootPath` 解析。
4. **渐进式工具加载**：内置 `skill_mcp_loader` 工具，按 SKILL.md 声明的 MCP Server 依赖按需加载（对应 Go 的 `WithProgressiveToolLoading`）。

在这些基础设施补齐前，请优先使用 [BaseAgent (TS)](./1.%20BaseAgent-通用的ReAct%20Agent%20(TS).md)。
