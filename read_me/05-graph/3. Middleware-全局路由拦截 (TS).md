Middleware 是图级别的全局执行拦截器，在每个节点执行**后**、确定下一跳**前**被调用，可以动态改变路由目标。它在 TS 版路由优先级里位于**最高层**。

> 本文是 [`3. Middleware-全局路由拦截.md`](./original/3.%20Middleware-全局路由拦截.md)（Go 版）的 TypeScript 对应版本，基于 Bun + TS SDK 实际代码（`src/core/graph.ts` 的 `Middleware` 类型、`src/core/application.ts` 的 `resolveNext`）编写。文末附 **Go ↔ TS API 映射表**，并标注两版的差异点。

---
中间件接口（TS）

```ts
import type { Command, Context } from "nexus-sdk-ts";

// Middleware 签名（src/core/graph.ts）
type Middleware = (
  name: string,          // 当前刚执行完的节点名
  cmd: Command | null,   // 该节点返回的 Command（可能含 goto/update）
  ctx: Context,
) => string[] | undefined; // 返回非空数组 = 重定向；undefined / [] = 不拦截，继续常规路由
```

> 差异（与 Go 不同点较多）：
> - Go 签名是 `func(ctx, nctx, currentNode string, callback) string`，TS 是 `(name, cmd, ctx) => string[] | undefined`。
> - TS **额外接收节点返回的 `cmd`**（Go 不传），中间件可据此判断节点意图。
> - TS **不接收 callback** 参数。
> - 返回类型：Go 返回单个字符串（`""` = 不拦截）；TS 返回 **`string[]`**（`undefined` 或空数组 = 不拦截），因此天然支持重定向到**多个并发节点**。

---
添加中间件

```ts
const g = new Graph();

// 逐个注册（链式，可多次调用）
g.useMiddleware(myMiddleware);

// 多个中间件：分多次调用，按注册顺序串联
g.useMiddleware(authMiddleware)
 .useMiddleware(loggingMiddleware)
 .useMiddleware(rateLimitMiddleware);
```

按注册顺序短路求值：**第一个返回非空数组的中间件生效，后续中间件不再执行**（见 `resolveNext`，`src/core/application.ts`）。

> 差异：Go 用变长参数 `g.AddMiddlewares(mw1, mw2, ...)` 一次加多个，并提供 `GraphMiddlewareChain` 组合器；TS 用 `g.useMiddleware(mw)` 单个注册（返回 `this`，可链式），**无** `AddMiddlewares` 变长版本，也**无** Chain 组合器。

---
中间件示例

示例 1：日志中间件（不改路由）

```ts
const loggingMiddleware: Middleware = (name, _cmd, ctx) => {
  console.log(`[Graph] 节点 '${name}' 执行完毕，当前状态:`, ctx.map());
  return undefined; // 不改变路由
};
g.useMiddleware(loggingMiddleware);
```

示例 2：全局错误恢复（Fallback）

```ts
const errorFallbackMiddleware: Middleware = (name, _cmd, ctx) => {
  const errMsg = ctx.getShared<unknown>("error");
  if (errMsg != null && name !== "error_handler") {
    // 避免死循环：已经在 error_handler 时不再重定向
    return ["error_handler"];
  }
  return undefined;
};
g.useMiddleware(errorFallbackMiddleware);
```

示例 3：速率限制

```ts
let requestCount = 0; // JS 单线程，无需加锁

const rateLimitMiddleware: Middleware = (name) => {
  requestCount++;
  if (requestCount > 100) {
    console.log(`Rate limit exceeded at node '${name}'`);
    return ["rate_limit_handler"];
  }
  return undefined;
};
g.useMiddleware(rateLimitMiddleware);
```

> 差异：Go 用 `sync.Mutex` 保护计数器；TS 单线程执行，普通自增即可（注意 `await` 间隙仍可能交错，必要时用更严谨的方案）。

示例 4：A/B 测试路由

```ts
const abTestMiddleware: Middleware = (name, _cmd, ctx) => {
  // 只在特定节点后介入
  if (name !== "user_input") return undefined;

  const userID = ctx.getShared<string>("user_id");
  if (userID && hash(userID) % 2 === 0) {
    return ["new_flow"]; // 50% 用户走新版本
  }
  return undefined; // 其他用户走正常流程
};
```

---
中间件的限制

1. **无内置自环防护**：TS 的 `resolveNext` 对中间件返回值**不做** `name !== target` 校验——若返回当前节点名，会路由回自身。Go 源码有此防护，**TS 没有**，唯一兜底是 `invoke` 的 `maxSteps`（默认 1000）。需要避免自环时，请在中间件内自行判断（如示例 2 的 `name !== "error_handler"`）。
2. **只在节点执行后调用**：中间件在 NodeFunc 执行完、`resolveNext` 决定下一跳时触发，无法在节点执行**前**拦截。
3. **全局作用域**：对所有节点生效，需在函数内用 `name` 判断来针对特定节点处理。
4. **第一个非空返回生效**：多个中间件按注册顺序短路，第一个返回非空数组者决定路由，其余不执行。

---
中间件 vs ConditionalEdge

| 特性 | Middleware | ConditionalEdge |
| --- | --- | --- |
| 作用范围 | 全局（所有节点） | 单个节点 |
| 拦截时机 | 节点执行后、路由决定前 | 节点执行后、路由决定前（相同） |
| 优先级（TS） | **最高**（高于 Command.goto） | 低于 Command.goto 和 Middleware |
| 返回值 | `string[] \| undefined` | `string \| string[]` |
| 适用场景 | 全局策略（限流、日志、A/B、错误兜底） | 节点特定的路由逻辑 |

> 差异：Go 文档称 Middleware「低于 Command，高于 ConditionalEdge」；TS 的 `resolveNext` 中 **Middleware 优先级最高**（先于 `Command.goto`）。以 TS 源码为准。

---
Go ↔ TS API 映射表

| Go API | TS API |
| --- | --- |
| `type GraphMiddleware func(ctx, nctx, currentNode string, cb) string` | `type Middleware = (name, cmd, ctx) => string[] \| undefined` |
| `g.AddMiddlewares(mw1, mw2, ...)`（变长） | `g.useMiddleware(mw)`（单个，可链式多次调用） |
| `schema.GraphMiddlewareChain(a, b, c)` | **无组合器**，多次 `useMiddleware` 即可 |
| `return ""`（不拦截） | `return undefined`（或 `[]`） |
| `return "error_handler"`（重定向单节点） | `return ["error_handler"]`（数组） |
| 无法重定向到多节点 | `return ["a", "b"]`（并发扇出） |
| `currentNode`（参数名） | `name`（参数名） |
| 入参无节点 Command | 入参含 `cmd: Command \| null` |
| 优先级：Command > Middleware > Conditional | 优先级：**Middleware > Command.goto > 条件边 > 静态边 > END** |
| 源码内置自环防护 | **无内置防护**，靠 `maxSteps` 兜底 |
