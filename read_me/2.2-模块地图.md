本章列出 Nexus SDK 所有包的职责、主要导出符号以及依赖关系。

---
包结构总览

code.byted.org/ad/nexus/
├── schema/              # ★ 核心接口层（所有其他包都依赖它）
├── agent/               # Agent 实现（BaseAgent、SkillAgent、FornaxAgent）
├── context/             # Context 实现
│   ├── nexuscontext/    #   内存 Context（开发/测试）
│   └── oceanaicontext/  #   平台 Context（生产）
├── llm/                 # LLM 实现
│   ├── fornax/          #   Fornax 平台
│   └── openai/          #   OpenAI/Azure/GPT-Openapi/ark方舟等
├── tool/                # Tool 实现
│   ├── file/            #   文件读写工具
│   ├── mcp/             #   MCP 协议工具（客户端侧）
│   ├── mcp_tool/        #   MCP 工具（服务端侧）
│   └── rag/             #   ByteRAG 检索
├── callback/            # Callback 实现
├── feedback/            # Feedback 反馈链
├── eval/                # DeepConf 评估引擎
├── node/                # 内置节点（HumanInLoop）
├── prompt/              # Prompt 模板引擎
├── log/                 # 日志
├── utils/               # 工具函数
├── output/              # 输出格式化
├── deploys/             # 部署模式
│   ├── http/            #   HTTP 服务器
│   └── lark/            #   飞书机器人
├── pkg/                 # 内部包
│   └── sandbox/         #   沙箱执行
├── constants/           # 常量
└── examples/            # 完整示例

各包详细说明

schema/ — 核心接口层

职责：定义所有核心接口和数据类型，是整个框架的契约层。

文件
主要导出
agent.go
Agent 接口、State、错误变量
llm.go
LLM 接口、GenerateOption、GenerateOptions
tool.go
BaseTool 接口、AskUserParam
callback.go
Callback 接口
context.go
Context 接口、Roadmap、Artifact、TurnIndex
graph.go
Graph、NewGraph、NodeFunc、Conditional、Option
application.go
Application、Invoke
command.go
Command、CommandBuilder、GotoNode、GotoEnd、GotoNodes
interruption_state.go
InterruptionState、InterruptionType 常量
llm_types.go
ChatCompletionMessage、ChatCompletionResponse、ToolCall

依赖：仅依赖标准库和 github.com/getkin/kin-openapi

agent/ — Agent 层

职责：提供开箱即用的 Agent 实现。

类型
文件
说明
BaseAgent
base.go
ReAct 循环 Agent，支持任意工具和 Feedback
SkillAgent
skill.go
加载本地/远程 Skill 文件的专用 Agent
FornaxAgent
fornax.go
对接字节 Fornax 平台的 Agent
OceanAIBase
oceanai.go
OceanAI 平台基础信息
Options
option.go

agent.WithName(name string)

agent.WithLLM(llm schema.LLM)

agent.WithCallback(cb schema.Callback)

agent.WithVar(k, v) / agent.WithVars(vars)
agent.WithAskUserTool(tool schema.BaseTool)
agent.WithFilterMemoryFunc(fn FilterMemoryFunc)
agent.WithContext(ctx schema.Context)
agent.WithTask(task string)
agent.WithTaskId(id int64)

callback/ — Callback 层

职责：提供可观测性回调实现。

类型
说明
EventCallback
基于事件的回调，支持自定义 Handler
Chain(...)
将多个 Callback 链式组合
LarkCallback
飞书消息推送回调

// EventCallback 创建
callback.NewEventCallback(
    callback.WithCustomHandler(func(ctx, nctx, event) { ... }),
)

// 多 Callback 组合
combined := callback.Chain(cb1, cb2, cb3)

feedback/ — Feedback 层

职责：对 Agent 输出进行质量评估和反馈循环。

类型
说明
Chain(fds ...Feedback)
将多个 Feedback 串联
JSONFeedback
验证 LLM 输出是否为合法 JSON

type Feedback interface {
    Feedback(ctx, nctx, agent, content string, toolCall *ToolCall) *FeedbackInfo
}

类型
说明

深度置信度算法实现

类型
说明

prompt/ — Prompt 层

包
说明

飞书机器人服务器

依赖关系图

    ↑
    ├── agent

    ├── llm/fornax
    ├── tool/*
    ├── callback

    ├── eval
    └── node

agent ← (depends on) → llm, feedback, prompt, schema
graph (schema) ← → agent, callback, context

deploys/http → schema, agent, context
deploys/lark → schema, agent, callback
